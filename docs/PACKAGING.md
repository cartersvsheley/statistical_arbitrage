# Packaging notes

This release reorganizes existing work for a GitHub portfolio. Modeling logic and recorded results are preserved. The launcher supplies portable paths, tests import from `src/model`, and the public notebook reads summary results instead of embedding an encoded price archive.

Personal absolute paths are removed from published run manifests. Raw/processed prices, third-party snapshots, binary workbook reports, caches, old archives and the large all-in-one notebook are excluded. Their absence does not imply permission to redistribute them elsewhere. Source construction and optional report scripts remain available.

Original project files were not deleted or overwritten. No repository was published by this packaging operation.
