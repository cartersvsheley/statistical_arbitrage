# Reuse and attribution

This packaging release does not choose an open-source license on behalf of the project owner. Public visibility alone should not be read as an unrestricted reuse grant. A license can be added separately when the owner chooses its terms.

Third-party packages and source data retain their own terms. The source manifest records data provenance; no raw price data is included. Project results are illustrative research outputs with the limitations documented in this repository.
