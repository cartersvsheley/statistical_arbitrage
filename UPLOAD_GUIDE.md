# Upload this package

1. Extract the ZIP and open the `ai-assisted-equity-pairs` folder.
2. Create or open the GitHub repository where this project should live.
3. Upload the contents of this folder, keeping the directory structure. Put `README.md` at the repository root; do not upload only the ZIP.
4. Confirm the README chart and `notebooks/research_demo.ipynb` render after upload.
5. Link the repository from your portfolio projects page.

Suggested repository name: `ai-assisted-equity-pairs`

Suggested description: “AI-assisted Python research exploring equity pairs through PCA, hierarchical clustering, and statistical testing, with reproducible code and documented limitations.”

Do not add local price archives, environments, or personal logs. `.gitignore` helps when using Git, but browser uploads still require choosing the intended files. An open-source license can be added separately once you choose its terms.
